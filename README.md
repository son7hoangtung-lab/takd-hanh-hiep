# Takd Hành Hiệp · 行侠记

Game võ hiệp Đại Việt vừa chơi vừa học tiếng Trung (HSK1). Kị sỹ Takd, chưởng môn Muay Việt, cùng chú Shiba đi từ làng Kim Liên đến Thăng Long và Vân Đồn.

**Chơi:** https://son7hoangtung-lab.github.io/takd-hanh-hiep/

Cài lên iPhone: mở link bằng Safari → nút Chia sẻ → Thêm vào MH chính.

- `index.html`, `js/`, `sw.js`, `manifest.webmanifest`: bản chạy (GitHub Pages phục vụ từ thư mục gốc)
- `src/`: trang nguồn và script build
